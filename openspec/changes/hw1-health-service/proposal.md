# Proposal: health-сервис в Docker

## Зачем

Нужен воспроизводимый сервис для HW1: любой проверяющий собирает образ из
корня репозитория и получает живой HTTP-ответ без ручной установки Python.

## Что меняется

- HTTP-сервис на Python 3.12 (стандартная библиотека), слушает порт 8080.
- `GET /health` возвращает JSON с `"status": "ok"`.
- `Dockerfile` с базовым образом `python:3.12-slim`, закреплённым digest.
- `uv.lock` как файл закреплённых зависимостей (зависимостей нет).
- `README.md` с командами `docker build` (контекст `.`) и `docker run` (порт 8080).

## Что не входит

- Аутентификация, метрики, бизнес-логика и другие маршруты.
- Docker Compose как единственный способ запуска.
- Пакетные зависимости Python: сервис использует только stdlib.
